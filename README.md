# Palmreach Support Services Website

Official website source for **Palmreach Support Services Pty Ltd**.

**Live domain:** https://palmreach.com.au

Palmreach is a Registered NDIS Provider supporting participants across Cairns and surrounding communities.

## Deployment

This is a static site designed for GitHub Pages under the GitHub account **Palmreach**.

Recommended repository: **Palmreach.github.io**.

- Publish from `main` branch, repository root.
- Custom domain is configured through the included `CNAME` file.
- Enable HTTPS in GitHub Pages after DNS resolves.

See `GITHUB-PUBLISHING-GUIDE.txt` for the complete setup instructions.
